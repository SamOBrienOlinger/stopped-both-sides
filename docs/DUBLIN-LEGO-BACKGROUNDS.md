All image files are 960px-wide WebP artwork. The same shared scene renderer is used on public and Garda pages. The action labels, explanatory content, characters, choices, legal sources, translations, scoring and route semantics are unchanged.

This imagery is decorative, has empty alt text, and should not be relied upon for factual claims about the geographic location of a scenario. The scenes use the existing character overlay and preserve the original indoor illustrations.
